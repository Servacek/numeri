Hodiny poháňa vlastný firmvér napísaný v C++ — beží priamo na čipe bez operačného systému.

Stiahnuť firmvér
  1. Stiahnite hex súbor tlačidlom vyššie.
  2. Pripojte USBasp programátor k hodinám.
  3. Nahrajte firmvér príkazom:
    avrdude -c usbasp -p m328p -U flash:w:numeri-firmware.hex:i
Celý repozitár
  1. Nainštalujte PlatformIO a klonujte repozitár.
  2. V adresári firmver/ upravte zdrojový kód podľa potreby.
  3. Zostavte projekt:
    pio run -e uno_usbasp_dev
  4. Nahrajte cez USBasp programátor:
    pio run -e uno_usbasp_dev --target upload
